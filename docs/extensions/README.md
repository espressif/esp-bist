"""
Test Results Extension - Usage Guide

This extension parses JUnit XML test report files and generates formatted RST output
for display in Sphinx documentation.

Features:
- Automatically parses JUnit XML reports generated by pytest
- Shows test pass/fail/skip counts and execution times
- Formats results as RST tables for documentation
- Updates automatically when test results change
- Works with both single and multiple testsuites

Configuration:

1. The extension is registered in docs/conf_common.py:

   extensions += ['xml_junit_test_report']

2. The extensions directory is automatically added to Python path

Usage in RST Files:

Basic usage - display test results from an XML report:

    .. test-results:: tests/cpu_reg_test/build/tests/report.xml

With options:

    .. test-results:: tests/cpu_reg_test/build/tests/report.xml
       :title: CPU Register Test Results

Directive Options:

- :title: (optional) Title to display above results

Output Format:

The directive generates a summary section showing:
- Total test count
- Pass/fail/skip counts
- Total execution time
- Detailed table with individual test cases, statuses, and times

Example Output:

    Test Summary:
    - Total: 2 tests
    - Passed: 2
    - Failed: 0
    - Skipped: 0
    - Total Time: 15.197s

    Testsuite: pytest

    ============  =======  ==========
    Test Case     Status   Time (s)
    ============  =======  ==========
    test_cpu...   ✓ PASS   10.147
    test_cpu...   ✓ PASS   5.050
    ============  =======  ==========

Path Resolution:

The report path is resolved relative to the project root (parent of docs directory).

Example:
    ``tests/cpu_reg_test/build/tests/report.xml``
    → looks for
    ``/home/tambor/projects/esp-bist/tests/cpu_reg_test/build/tests/report.xml``

CI Integration:

Test reports are generated during GitLab CI test jobs:
- QEMU tests: tests/<app>/build/tests/report.xml
- Hardware tests: tests/<app>/build/tests/report.xml

Reports are cached in CI, so documentation builds will include the latest test results
from the previous CI run.

"""
